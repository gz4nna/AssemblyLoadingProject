全局默认参数

所有插件共享的一套兜底连接参数（host / user / pwd / port 等），保存于 SQLite（plugins.db），不会写入代码。插件未在"配置 → 执行参数"中指定时，使用这里的值；插件级执行参数会覆盖默认参数。

提示：以 key 名区分用途。例如 SQL Server 用 SqlServerHost / SqlServerDb / SqlServerUser / SqlServerPwd / SqlServerPort；MySQL 用 MySqlHost / MySqlDb / ...；Sybase 用 SybaseHost / SybaseDb / ...。
